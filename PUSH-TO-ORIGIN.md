# Push to origin

Repo is committed on branch `main`. To push to your remote:

```bash
git remote add origin <YOUR_REPO_URL>
git push -u origin main
```

Example (GitHub):
```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

If your remote already exists, just run:
```bash
git push -u origin main
```
